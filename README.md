## What I Care About

- **The details nobody put in the spec**: a character standing perfectly still reads as broken. The half-second of idle sway isn't a requirement anywhere, and it's the difference between alive and not
- **Undocumented behavior**: the interesting bugs live in the gap between what a library says and what it does
- **Writing down why**: decisions outlive the people who made them, and an agent picks up a repo faster when the reasoning is in the tree
- **Giving fixes back**: if a library breaks at work, the fix goes upstream — [Android-PullToRefresh (#56)](https://github.com/chrisbanes/Android-PullToRefresh/pull/56), [msgpack-java (#18)](https://github.com/msgpack/msgpack-java/pull/18), [UnityCapture (#36)](https://github.com/schellingb/UnityCapture/pull/36), [uWindowCapture (#5)](https://github.com/hecomi/uWindowCapture/pull/5), [MRTK-Profiles-for-NrealLight (#4)](https://github.com/TakashiYoshinaga/MRTK-Profiles-for-NrealLight/pull/4). Doing this since 2012
